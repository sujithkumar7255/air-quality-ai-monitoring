About The Project

AI-based Air Quality Prediction and Analysis

🎯 Objective

To analyse air pollution and predict the Air Quality Index using historical pollutant data and machine learning.

📊 AQI Analysis

The system calculates pollutant indices and determines AQI using the maximum sub-index approach.

🤖 Machine Learning

Machine learning techniques are used to predict air quality values and classify air quality categories.

🌍 Environmental Monitoring

The system can support pollution monitoring and improve awareness and preparedness.

System Modules

Major components of the proposed system

01. Data Collection

Collects historical air quality data including pollutant, location, date and monitoring station information.

02. Pre-Processing

Handles missing values, invalid values and outliers before machine learning analysis.

03. AQI Calculation

Calculates individual pollutant indices and determines the overall AQI.

04. Model Training

Training and testing datasets are used to build machine learning models.

05. AQI Prediction

Predicts AQI values and air quality categories using machine learning.

06. Testing

Tests functions using valid and invalid inputs to verify system reliability.
